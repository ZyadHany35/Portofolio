## Design Direction
- **Minimal layout** with generous white space
- **High-contrast headings** (dark text on white background)
- Card-style components for projects and experience
- Smooth scroll navigation between sections
- Sticky/fixed top navigation bar with section links
- Mobile-first responsive design

## Accessibility & UX
- WCAG AA contrast ratios on all text
- Full keyboard navigation support
- Mobile-first responsive breakpoints

## SEO
- Proper meta title (≤60 chars) and description (≤155 chars)
- Semantic HTML structure
